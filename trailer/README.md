# 《一线千愿》社媒预告片

45.6 秒 · 1080×1920（9:16）· 30fps · 带声音。

没有用任何剪辑软件：**画面**是 Chromium 逐帧截图，**声音**是 Node 算出来的 WAV，
**配图**（露珠、蛛网、海报、二维码）都是场景里现画的 SVG 与 canvas。
三个文件就够重跑一遍。

## ⚠️ 先看这个：素材分两套，别拿错

小红书因为「网址 + 二维码」把笔记拦了（审核细则第 2 条点名了网址和二维码）。所以现在出两版：

| 目录 | 落版画的是什么 | 能发哪 |
|---|---|---|
| `out/平台版/` | 只打「一线千愿」四个字 + 一句「在搜索框里写下这四个字」，**没有网址、没有二维码** | 小红书、抖音、视频号等站内平台 |
| `out/官网版/` | 网址 `uncodeapps.icu` + 可扫的二维码 | B 站、知乎、微博、即刻、微信公众号、自己的页面 |

两套的**画面其余部分完全一样**，只有落版不同（`scene.html?ending=brand` 切过去）。
平台版连揭幕那一幕的二维码也一起藏了，因为那一颗也能扫到站外。

配图同理：平台版的 `配图-4.jpg` 只有编号、没有二维码；官网版的带二维码。

## 让「一线千愿」这四个字能被搜到

平台版不能给链接，那用户怎么找过来？**靠名字。**
但我查过了，**现在搜索引擎里搜「一线千愿」一条结果都没有**，所以这条路现在还不通。
我把仓库里能做的先做了，剩下要拿账号去做的也写在下面。

### 已经做好的（在仓库里）

- `index.html`：补了 `rel=canonical` / `og:url` / `og:image` / `og:site_name` / `og:locale` / `twitter:card`，
  以及一段 `WebSite` 结构化数据，把「一线千愿 / 蛛丝许愿馆 / One Thread, A Thousand Wishes」绑到 `https://uncodeapps.icu/`。
- `sitemap.xml`：新增，并且 `build-vercel.mjs` 已经把它一起输出进 `public/`，部署后就是 `https://uncodeapps.icu/sitemap.xml`。
- `robots.txt`：加了 `Sitemap:` 那一行（站点本来就允许抓取，只挡了后台与数据目录）。
- `assets/og-cover.jpg`：1200×630 的分享卡，微信、知乎、B 站抓链接预览时用的就是它。
- `index.html` 里预留了两行注释掉的验证 meta，拿到验证码填上即可。

### 还要你做的

1. **先部署**：提交并推上去，Vercel 会重跑 `build-vercel.mjs`，把新的 `index.html`、`sitemap.xml`、
   `assets/og-cover.jpg` 一起发出去。验证类的东西不部署就等于没填。
2. **Bing**：验证码已经填进 `index.html` 的 `msvalidate.01` 了。部署完回到那个页面点「验证」，
   通过后提交 `https://uncodeapps.icu/sitemap.xml`。Bing 收录比百度快得多，索引还会被别的引擎借用。
3. **百度搜索资源平台** → 添加站点 `uncodeapps.icu` → 验证方式选「HTML 标签」→
   把给的 `<meta name="baidu-site-verification" …>` 填进 `index.html` 里预留的那一行（现在还是注释）→ 再部署一次 → 提交 sitemap。
4. 想在 Bing 上更快：可以上 IndexNow（一个放在根目录的密钥文件 + 一次 POST），
   能跟现有的定时任务接起来，改动即刻推送。需要的话再说。
3. 等。首次收录通常 3 天到 4 周。**这期间小红书只负责让人记住名字，点击入口放在允许外链的地方。**
4. 想让名字更快被搜到，下面这些地方各发一次（收录快、也允许放链接），标题里都写「一线千愿」：
   知乎回答或文章、B 站视频简介、微博、微信公众号文章（用「阅读原文」）、豆瓣、即刻、少数派。
   爬虫从这些页面读到的就是这四个字。

### 关于小红书站内

- 正文和图片里都不要出现网址、二维码、微信号、其他平台名称，也不要有「点击链接」「扫码」这类字样。
- 「一线千愿」可以做成话题标签，用户站内搜到的是你的笔记——但笔记本身进不了站外，所以转化只能靠用户自己出去搜品牌名。
- 确实要在小红书里直接可点，唯一合规的路是**企业专业号**认证后挂官网链接/组件。个人号做不到，
  绕过去（图里塞网址、评论区发链接）基本都会被拦，而且会累积违规。

### 如果平台版还是被拦

最可能被机器挑出来的是落版那句 **「在搜索框里写下这四个字」**。
在 `scene.html` 里搜这句，换成空字符串，或者只留「一线千愿 · 蛛丝许愿馆」，然后重跑：

```bash
node render.mjs brand
```

## 重跑

```bash
cd trailer
npm install                        # puppeteer-core + @ffmpeg-installer/ffmpeg + @fontsource/noto-serif-sc

node audio.mjs                     # 生成 out/trailer.wav（纯计算，秒出）
node render.mjs                    # 官网版（约 9 分钟）
node render.mjs brand              # 平台版（约 9 分钟）

# 两套封面与配图
node render.mjs stills 3 13.8 21.9 27.6 30.6 35.4 45
node render.mjs stills brand 3 13.8 21.9 27.6 30.6 35.4 45
node cover.mjs

node render.mjs og                 # 重新生成 assets/og-cover.jpg（分享卡）
node render.mjs stills 21.6 35.4   # 只出静帧，改稿时看画面
node serve.mjs                     # 人工预览：http://127.0.0.1:4173/trailer/scene.html
```

改内容的位置：

- 每一幕的入场时刻：`scene.html` 顶上的 `T_TITLE / T_NIGHT / T_CAST / …`
- 换丝的时刻：`ACCENT`
- 落版的两种形态：`?ending=brand` 与 `?ending=url`（样式里 `html[data-ending="brand"]` 那几条）
- 尺寸：`render.mjs` 里的 `W / H / FPS`
